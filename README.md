# حضورینو — اپلیکیشن اندروید

نسخه ۴، حضور و غیاب کاملاً آفلاین برای گوشی شخصی هر کارمند است.

## امکانات

- فعال‌سازی یک‌باره با نام، کد پرسنلی و رمز شخصی
- ثبت جداگانه ورود و خروج با اثر انگشت امن خود گوشی
- ثبت با رمز شخصی به‌عنوان روش جایگزین
- آمار روزانه و تاریخچه تردد روی همان گوشی
- بدون دوربین، تشخیص چهره، اینترنت یا ذخیره اثر انگشت

اثر انگشت توسط پنجره امن Android BiometricPrompt بررسی می‌شود و اپ فقط نتیجه موفق یا ناموفق را دریافت می‌کند.

## ساخت APK

گردش‌کار GitHub Actions با هر Push روی شاخه main فایل APK جدید را ساخته و در Release با برچسب debug-latest منتشر می‌کند.
