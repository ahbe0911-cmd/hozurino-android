# حضورینو — اپلیکیشن اندروید

نسخه اولیه Native Android برای نصب روی گوشی هر کارمند.

## قابلیت‌های پیاده‌سازی‌شده
- رابط فارسی و راست‌چین با Jetpack Compose
- تأیید واقعی اثر انگشت/بیومتریک از طریق Android BiometricPrompt
- ورود با کد پرسنلی و اعتبارسنجی طول کد
- مسیر ثبت/تأیید چهره و صفحه موفقیت

## اجرای پروژه
پوشه را در Android Studio باز کنید، Gradle Sync را اجرا کنید و روی گوشی Android 8 یا بالاتر Run بزنید.

## ساخت APK در GitHub
گردش‌کار `.github/workflows/build-apk.yml` با هر Push روی شاخه main اجرا می‌شود. پس از موفقیت Build، فایل `Hozurino-debug-apk` از بخش Artifacts همان اجرای GitHub Actions قابل دانلود است.

## نکته فنی چهره
صفحه دوربین و رابط آماده است، اما شناسایی هویت واقعی چهره باید به سرویس امن یا مدل FaceNet/ArcFace و بررسی زنده‌بودن متصل شود. ML Kit به‌تنهایی فقط وجود و مشخصات صورت را تشخیص می‌دهد و هویت افراد را تعیین نمی‌کند.

## مرحله تولید
برای استفاده سازمانی باید API سرور، ثبت پرسنل، توکن دستگاه، ثبت موقعیت اختیاری، ذخیره آفلاین و همگام‌سازی، رضایت‌نامه بیومتریک و پنل مدیریت اضافه شود.
